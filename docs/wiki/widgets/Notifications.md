# Notifications

[Widgets](../Widgets.md) · [Bar](../Bar.md) · [Wiki](../README.md)

Status: **Not implemented as a widget.**

The notification widget crate is currently empty and is not included in the bar.
D-Bus notification service code exists separately, but does not constitute a
usable notification widget or notification center.

## Setup and configuration

There are no supported notification-widget interactions or `[notifications]`
settings. This page is reserved for service setup, notification history, popup
behavior, and options as they become implemented.

Implementation: [widget source](../../../crates/ghost-shell-widgets/ghost-shell-widget-notifications/src/lib.rs).
