# Launcher

[Wiki](../README.md#configuration) · [Introduction](Introduction.md)

The launcher discovers desktop application entries and filters them as you type.
It launches the selected entry through Niri's spawn command. Desktop entries
marked as terminal applications currently run through `ghostty -e`; the terminal
choice is hard-coded and cannot yet be changed in TOML.

```sh
ghost-shell-launcher
```

Press Enter to launch the selected application and Escape to close the launcher.
The centered overlay lets Niri choose the active output. It takes exclusive
keyboard focus. Use Up/Down or click to select a result. It exits after
successful launch, Escape, or surface closure. No background service or IPC
server is needed. A process lock prevents duplicate instances; pressing the
shortcut again does not toggle it. Desktop discovery runs in the background
while the window opens.

Quoted executable paths are supported, including the doubled quotes around an
absolute executable path generated by some GlobalProtect packages. This
compatibility handling does not modify the installed desktop file.

Desktop entries without a name or whose `Exec` command cannot be parsed are
skipped. The application logs a warning with the desktop file path and reason,
so a rejected entry does not prevent startup. If an application is missing,
check the application logs for `Skipping desktop entry`.

## Configuration

Put these settings in `~/.config/ghost-shell/config.toml`.

```toml
[launcher]
blur = true
background_opacity = 0.8
```

  | Option               | Default   | Behavior                                                 |
  | -------------------- | --------- | -------------------------------------------------------- |
  | `blur`               | `false`   | Requests compositor blur behind the launcher             |
  | `background_opacity` | Automatic | `0.8` with blur, otherwise `1.0`; clamped to `0.0`–`1.0` |

The [general font and theme](Introduction.md#theming) also apply. There are no
launcher-specific terminal, application-directory, or key-binding settings in
the TOML schema.
